🚀 Overview

Artery is a powerful AI system assistant built to redefine how users interact with their computers.
It combines voice interaction, system automation, and real-time monitoring into a single intelligent layer.

Unlike traditional assistants, Artery doesn’t just wait for commands —
it understands context, executes intelligently, and protects the system continuously.

⚡ Key Highlights
🎙️ Voice-Controlled System
Natural interaction with your computer
⚙️ Instant Task Execution
OS & application-level automation
🧠 Behavior Awareness
Learns patterns and improves over time
🔐 Built-in Security
Monitors system health and detects threats
👤 User Authentication
Detects authorized users and restricts access
🌐 Offline-First Design
Works locally with optional online capabilities

Easily extend features without touching core code
